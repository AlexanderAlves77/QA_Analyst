# Contribuindo

Obrigado pelo interesse em contribuir com o Enterprise Automation Framework.

## Antes de abrir um Pull Request

- Leia o README
- Consulte o ROADMAP
- Verifique o CHANGELOG

## Padrões

- Utilize Conventional Commits
- Respeite a arquitetura do projeto
- Escreva código limpo
- Atualize a documentação quando necessário

## Filosofia

Toda contribuição deve melhorar o Framework sem comprometer sua arquitetura.
